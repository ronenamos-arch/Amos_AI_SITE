§ 01 — Intelligence Tiers
המודלים של Claude
שלושה מודלים, החלטה אחת — איך לבחור את רמת האינטליגנציה הנכונה למשימה הפיננסית שלך.
Haiku 4.5
// FAST · EFFICIENT
סוס העבודה היומיומי של האנליסט. תגובות מהירות למשימות שגרתיות — סיווג תנועות, ניסוח מהיר של מזכרים, עזרה בנוסחאות אקסל ושאילתות נתונים.
מתאים ל: משימות חוזרות, שאלות מהירות, תהליכים בזמן אמת
Sonnet 4.6
// BALANCED · RECOMMENDED ✦
המודל המועדף של ה-CFO. עומק יוצא דופן למידול פיננסי, ניתוח סטיות, מצגות לדירקטוריון וחשיבה אסטרטגית — בקצב שמכבד את הלו"ז שלך.
מתאים ל: FP&A, דיווח, ניתוחים, סטוריטלינג
Opus 4.7
// PINNACLE · DEEP REASONING
חשיבה מורחבת לבעיות פיננסיות מורכבות. מידול M&A, תכנון רב-תרחישי, סינתזה רגולטורית, והחלטות שדורשות ניתוח מעמיק לעומק.
מתאים ל: מודלים מורכבים, M&A, תכנון אסטרטגי
// FOR FINANCE LEADERS
איזה מודל כדאי לי להשתמש?
חשבים ורואי חשבון: Haiku להתאמות והשוואות, Sonnet לניתוחי סגירת חודש ו-commentary
FP&A ו-VP Finance: Sonnet לתקצוב וניתוח סטיות, Opus לתכנון ארוך טווח
CFOs ומנהלי כספים: Sonnet לאינטליגנציה יומיומית, Opus לאסטרטגיה ול-M&A

// STARTER
"Analyze the key risks in a company where revenue grew 18% but gross margin declined 400bps. What are the five most likely root causes, and which KPIs would you investigate first as CFO?"
// ADVANCED — Use with Opus 4.7 + dataset below

COGS drivers: hosting +$2.1M, third-party APIs +$1.8M, CS headcount +$1.4M, implementation services +$0.9M. Enterprise customers +40%, SMB churn 22%. Use extended thinking to: (1) diagnose margin compression with root-cause weighting, (2) model the impact of three strategic responses over 18 months, (3) produce a sequenced action plan with expected margin recovery per quarter and owner accountability."

Claude ב-PowerPoint
מדאטה ועד מצגת לדירקטוריון תוך דקות — Claude כותב, מובנה ומשפר את המצגות הפיננסיות שלך בתוך PowerPoint.
// WHAT IS IT?
Claude כאסטרטג מצגות שלך ב-PowerPoint
Claude in PowerPoint הוא add-in נטיב שמביא את Claude אל ה-workflow של המצגות שלך. בחר שקופית, תיבת טקסט או מצגת שלמה ובקש מ-Claude לשכתב תוכן, לשפר נרטיבים פיננסיים, להוסיף סיכומי הנהלה, לארגן מחדש לוגיקת שקופיות או לייצר speaker notes. צוותי פיננסים משתמשים בזה כדי להפוך ייצואי דאטה גולמיים למצגות CFO מלוטשות תוך הפחתה דרמטית של זמן הכנת דירקטוריון.
Starter Prompt
העברת הנרטיב של מצגת הדירקטוריון
הורד את דאטהסט הדירקטוריון למטה, ואז השתמש ב-prompt הזה ב-PowerPoint עם ה-add-in של Claude כדי לייצר תוכן שקופית מוכן להנהלה.
// STARTER
"Rewrite this slide for a CFO board presentation. Transform the bullet points into a three-sentence executive insight. First: key financial result. Second: primary driver. Third: outlook or recommended action. Use confident, direct language."
// ADVANCED — Full 8-Slide Board Pack Generation
"Using the data I paste, generate a complete 8-slide board pack. For each slide provide: insight-led title (max 8 words), three talking points in CFO voice, and speaker notes with the top two anticipated board questions. Slides: (1) Executive Summary — 3 headlines + CFO action; (2) P&L Summary table vs budget and prior year; (3) Revenue bridge narrative; (4) Gross margin walk and commentary; (5) OpEx analysis by department; (6) Cash flow and balance sheet highlights; (7) Revised FY guidance and assumptions; (8) Risks and mitigations. Format for direct paste into PowerPoint."
