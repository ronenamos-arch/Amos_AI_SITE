SLIDE 03 · מה זה Skill

מתכון עבודה ש-Claude זוכר — כדי שלא תכתבו אותו Prompt פעמיים

תארו לעצמכם שבכל סוף חודש אתם כותבים את אותו Prompt ל-Variance Commentary. Skill הוא הדרך לשמור את ההוראות האלה פעם אחת — וכל פעם שצריך, פשוט מפעילים אותן בשם. זה כמו מתכון עבודה למטבח: כתבתם פעם איך מכינים את המנה, ומאז כל מי שפותח את המתכון מקבל בדיוק את אותה תוצאה. ה-Skill הוא הזיכרון המוסדי של מחלקת הכספים שלכם — עקבי, חוזר על עצמו, וניתן לשיתוף עם הצוות.

SLIDE 04.5 · מה יש בתוך SKILL.md?

הקובץ שמנחה את Claude

דוגמה למבנה בתוך SKILL.md — כך נראה סקיל Variance Commentary מבפנים.

  1. # Variance Commentary Skill
  2.  
  3. ## 1. Name
    Variance Commentary
  4.  
  5. ## 2. Description
    כותב ניתוח סעיפים בין תקציב לבפועל (Variance) בטקסט מקצועי וברור.
  6.  
  7. ## 3. When to Use
    כשמתעדכנת טבלת Budget/Actual עם נתונים חדשים.
  8.  
  9. ## 4. Instructions
    - לפי כל שורה מעל Threshold.
    - הסבר את הסיבה העיקרית לחריגה.
    - הצע פעולה מומלצת.
    - כתוב בשפה ברורה ומקצועית.
    - מבנה הפלט: Summary, Drivers, Action.
  10.  
  11. ## 5. Input Format
    טבלה עם עמודות: Account, Budget, Actual, Variance, % Variance
  12.  
  13. ## 6. Output Format
    Markdown עם שלושה חלקים: Summary, Drivers, Action
  14.

SLIDE 06 · הדגמה חיה 1

בונים ביחד — Variance Commentary Skill

הסקיל הכי שימושי לכל CFO וקונטרולר: מקבל נתוני Actual vs Budget ומחזיר commentary מקצועי, קצר ואחיד — לכל שורה בדוח.

האתגר
כל סגירת חודש, מישהו כותב ידנית הסברים לחריגות בדוח — בטון שונה, באורך שונה, ולפעמים שוכח לציין פעולה נדרשת.
הפתרון — הגדרת הסקיל
SKILL.md — fpa-commentary
--- name: fpa-commentary description: Writes FP&A variance commentary for the CFO pack. Use when asked for monthly commentary, variance analysis, or CFO reporting. --- # FP&A Commentary When writing variance commentary: 1. Start with a 2-sentence executive summary 2. Call out the top 3 drivers (positive and negative) 3. One paragraph per business unit 4. Flag anything +/- 5% vs budget 5. Tone: direct, no jargon, CFO-ready
מה זה נותן
  • אותו פורמט בכל שורה, בכל חודש, לא משנה מי בצוות מפעיל את זה
  • חוסך את הכתיבה הידנית החוזרת של אותו סוג ניתוח
  • קל לעדכן — משנים שורה אחת ב-Instructions וכולם מקבלים את השינוי
מתחילים — מבקשים מ-Claude לבנות את הסקיל יחד
Claude שואל מה הסקיל צריך לעשות — ומגדיר אותו בפועל

מריצים על נתוני חברה לדוגמה (Q2 2026)

  • COGS: 8.2M$ מול 7.6M$ (+7.9%)
  • Gross Profit: 14.2M$ מול 15.4M$ (-7.8%)
  • OpEx: 10.3M$ מול 9.9M$ (+4.0%)
  • EBITDA: 3.9M$ מול 5.5M$ (-29.1%)

SLIDE 09 · גבולות ובטיחות

מה סקיל לא אמור להכיל

סקיל הוא לא תוכן סטטי — הוא הופך להוראות שה-AI פועל לפיהן. הנה הגבולות שמבטיחים שהוא עוזר, ולא מסכן.

✓ מה כן
איפה סקיל עוזר
  • זיכרון מוסדי לצוות — כולם מקבלים אותה איכות פלט
  • עקביות מוחלטת בפורמט ובטון בין הרצות
  • חוסך כתיבה חוזרת של אותן הוראות שוב ושוב
  • קל לעדכן — שינוי אחד במקום אחד משפיע על כולם
! תמיד לעצור
איפה חייבים להיזהר
  • לעולם לא להכניס סיסמאות, מפתחות API או מידע רגיש לתוך הסקיל
  • לא לסמוך על מספרים שיכולים להתיישן (מדרגות מס, תעריפים) בלי לציין שצריך לבדוק מול המקור
  • לא להחליף שיקול דעת מקצועי בפלט אוטומטי
  • לבדוק כל סקיל שמישהו אחר שלח לפני שמתקינים אותו
