איפה Excel נשבר

  • נפח: מיליוני שורות GL מאטים את Excel לסחיבה — ולפעמים קורסים אותו.
  • גרסאות: "Budget_FINAL_v3_REVISED.xlsx" הוא לא ממשל. אין audit trail, אין rollback.
  • שלבים ידניים שבירים: כל VLOOKUP, כל copy-paste — נקודת כשל פוטנציאלית.
  • תלות באדם: כשהאנליסט עוזב — הידע עוזב איתו. סקריפט Python מתועד מעצמו.
  • אין חיזוי: Excel מחשב את העבר. Python יכול לנתח את העתיד.

מודול 5 · קוד מלא
Variance Analysis אוטומטי

סקריפט מוכן לייצור להשוואת תקציב מול ביצוע מול שנה קודמת. העתק, הדבק, הרץ.

מה זה מחליף ב-FP&A רגיל: הורדת שני אקספורטים, מיזוג עם VLOOKUP, נוסחאות, עיצוב מותנה, מיון — 90–180 דקות. הסקריפט הזה: 3 שניות, זהה בכל פעם.
budget_vs_actual_variance.py Python 
import pandas as pd
import numpy  as np

# נתוני קלט — החלף עם pd.read_csv() בייצור
depts   = ["מכירות", "פיתוח", "G&A", "תפעול", "CS"]
budget  = [4_200, 3_850, 1_900, 2_600, 1_450]
actual  = [4_510, 3_720, 2_085, 2_590, 1_380]
prior_y = [4_100, 3_500, 1_750, 2_450, 1_310]

df = pd.DataFrame({
    "מחלקה"  : depts,
    "תקציב"  : budget,
    "ביצוע"  : actual,
    "שנה_קודמת": prior_y,
})

df["Variance"]    = df["תקציב"] - df["ביצוע"]
df["Variance_%"]  = (df["Variance"] / df["תקציב"] * 100).round(1)
df["YoY_%"]       = ((df["ביצוע"] - df["שנה_קודמת"]) / df["שנה_קודמת"] * 100).round(1)
df["סטטוס"]       = df["Variance"].apply(lambda v: "⚠ חריגה" if v<0 else "✓ תקין")

ranked = df.sort_values("Variance", ascending=True).reset_index(drop=True)

print("=" * 50)
print(f"  תקציב כולל:  {df['תקציב'].sum():,.0f} אלש\"ח")
print(f"  ביצוע כולל:  {df['ביצוע'].sum():,.0f} אלש\"ח")
print(f"  Variance:     {df['Variance'].sum():,.0f} אלש\"ח")
print("=" * 50)
print(ranked.to_string(index=False))
# ranked.to_csv("variance_output.csv", index=False)
