# AI Finance Agent — START

ברוך הבא לסביבת העבודה (Project) של **AI Finance Agent**.
זוהי ערכת התחלה לקורס Claude לאנשי כספים — מותאמת לחברת הדוגמה **TechFlow Ltd**.

## מה זה
Project עם זיכרון לעבודה פיננסית חוזרת מול Claude Cowork. הרעיון:
- לשמור את כל קובצי המקור במקום אחד
- לאפשר הוספת חוזי ספקים חדשים כקובצי PDF
- לעדכן את מרשם החוזים (Contract Register) כשצריך
- להשוות הוצאות ספקים מול המרשם
- להפיק סיכומים ופלטים לבדיקה
- לשמור הקשר שימושי להרצה הבאה

## מבנה התיקיות

```
AI-Finance-Agent/
├── START.md      ← הקובץ הזה — הוראות הפרויקט
├── MEMORY.md     ← זיכרון מתמשך (החלטות, מיפויים, הקשר)
├── TASKS.md      ← מעקב משימות (To Do / Done)
│
├── data/                    ← קובצי מקור
│   └── incoming_contracts/  ← חוזי ספקים חדשים (PDF) להוספה
├── analysis/                ← קבצי עבודה זמניים
└── reports/                 ← פלטים סופיים לבדיקה
```

## הקשר החברה (TechFlow Ltd)
- חברת SaaS B2B ישראלית, מטבע USD, ARR $18M, ~150 עובדים
- 3 מוצרים: Enterprise ($1.2K), SMB ($300), Starter ($60)
- דיווח רבעוני לדירקטוריון + חודשי להנהלה

## איך עובדים בסביבה הזו
1. שים קובצי מקור ב-`data/`
2. הכנס חוזי ספקים חדשים (PDF) ל-`data/incoming_contracts/`
3. בדוק ב-`TASKS.md` מה צריך להיעשות
4. השתמש ב-`MEMORY.md` לשמירת מה שחשוב שיישאר להרצה הבאה
5. שמור קבצי עבודה ב-`analysis/`
6. שמור פלטים סופיים ב-`reports/`

## תהליך עבודה טיפוסי
1. הוסף או סקור קובצי מקור
2. קלוט חוזי PDF חדשים מ-`incoming_contracts/`
3. עדכן את מרשם החוזים
4. השווה הוצאות ספקים מול החוזים — חפש פערים ואי-התאמות
5. כתוב סיכום ממצאים קצר ושמור ב-`reports/`
6. שמור מיפויים והחלטות שימושיים ב-`MEMORY.md`
