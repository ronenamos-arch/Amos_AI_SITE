פשוט מהגיליון

Claude Inside Excel
40–50 דקות Excel Add-in
למה Claude בתוך Excel?

הנתונים כבר בגיליון — למה להעתיק החוצה?

אתה מבלה את רוב היום ב-Excel. עם Claude Excel Add-in אתה לא צריך להעתיק נתונים ל-Claude ובחזרה — אתה מסמן טווח בגיליון, מריץ Claude, והתוצאה חוזרת ישר לתא או ל-Sidebar.

התקנת ה-Add-in

4 שלבים להתקנה

1
פתח Excel → Insert → Get Add-ins
בלשונית Insert, לחץ על "Get Add-ins" (חנות התוספות של Office).
2
חפש "Claude" והתקן (Add)
חפש את התוסף הרשמי של Anthropic ולחץ Add להתקנה.
3
התחבר לחשבון Claude
היכנס עם אותו חשבון Claude — ה-Sidebar ייפתח בצד הגיליון.
4
סמן טווח והתחל לעבוד
בחר תאים, כתוב הוראה ב-Sidebar, וקבל תוצאה בגיליון.

Excel Guides

כאן תמצא שני קובצי Excel מלאים עם דוגמאות וסט פרומפטים מוכנים לשימוש, שמאפשרים עבודה מידית עם Claude לניתוח שונות, בניית דשבורדים, ניקוי נתונים וכל סיוע טבלאי נוסף.

פתח כל קובץ ובדוק איך עובדים עם Claude ישירות מתוך הגיליון, צעד אחר צעד, על גבי הנתונים עצמם.

תבניות Prompt ל-Excel

נוסחים מוכנים להדבקה ב-Sidebar

שים לב — ב-Excel אתה לא מדביק נתונים. אתה מתאר מה לעשות עם הטווח המסומן.

תבנית — Commentary לטווח מסומן
For the selected range, add a new column "Commentary". For each row where variance > 5% or > $10K, write one sentence explaining it. Leave other rows blank. Language: English, past tense, professional.
ה-Insight הכי חשוב

Claude ב-Excel הופך משימות של "שורה-אחר-שורה" לפעולה אחת. במקום לכתוב 40 הערות variance ידנית — אתה מסמן, מריץ, ומקבל את כולן בעמודה אחת.

תרגיל 08 הרץ Commentary על לשונית Budget vs Actuals

פתח גיליון עם נתוני TechFlow Q2 (Budget מול Actual לכל שורת P&L). סמן את הטווח, פתח את Claude Sidebar, והרץ את ה-Starter Prompt. אז נסה את ה-Advanced על לשונית Trial Balance.

Starter — Variance Commentary (inside Excel)
For each row in the selected range where variance exceeds $10K or 5%, write one sentence of management commentary explaining the variance. Use this format: "[Line item] [direction] due to [reason]." Language: English, professional, past tense.
Advanced — Trial Balance Cleanup
Clean this Trial Balance: - Standardize account names to a consistent naming convention - Remove duplicate rows - Flag accounts with a zero balance - Sort by account code ascending Output the cleaned table back into the sheet.
