מה זה Connector?

במקום להעלות קבצים — Claude מתחבר ישירות

עד עכשיו, כדי ש-Claude ינתח דוח, היית מוריד אותו, מעלה ל-Claude, ומדביק. עם Connector (המנגנון נקרא MCP) — Claude מתחבר ישירות ל-Google Drive, Notion או SharePoint שלך, וקורא את הקבצים בעצמו.

📋
בלי Connector — Copy-Paste
מוריד קובץ → מעלה ידנית → מדביק נתונים. בכל פעם מחדש. כמו להעתיק מסמך ביד.

Claude מחובר למקור ושולף את הקובץ העדכני לבד. כמו לחבר כבל — המידע זורם.

• רק לאחר אישור הרשאה שלך

🔒 מה נשאר מוגן
• הסיסמאות שלך — לעולם לא נחשפות
• אתה שולט בהרשאות ומבטל בכל רגע
• קבצים שלא ביקשת — לא נקראים
חיבור Google Drive

4 שלבים לחיבור

1
Settings → Connectors → Google Drive
פתח את הגדרות החשבון ובחר את Google Drive מרשימת ה-Connectors.
2
בדוק את ה-Tools של ה-Connector
לפני החיבור, ראה אילו פעולות (Tools) ה-Connector חושף — קריאה, חיפוש, יצירה. כך תדע בדיוק מה Claude יוכל לעשות.
3
אשר הרשאות (Authorize)
התחבר לחשבון Google ואשר אילו Tools מותרים — Read-only או גם כתיבה. אתה בשליטה מלאה על כל פעולה.
4
בקש קובץ לפי שם בשיחה
פשוט כתוב "Access the file ... from my Drive" — Claude ישלוף ויקרא.
ה-Insight הכי חשוב

Connector הופך את Claude מ"כלי שמנתח מה שהדבקת" ל"עוזר שיודע איפה הקבצים שלך". במקום לחפש את הדוח — פשוט מבקשים אותו בשם.

תרגיל 07 חבר את Drive ונתח Board Pack בלי להעלות אותו

קודם חבר את Google Drive (לפי 3 השלבים למעלה). ודא שיש בו קובץ בשם "TechFlow Board Pack Q2 2026" (אפשר ליצור קובץ דמה). אז הרץ את ה-Prompt — Claude ישלוף ויסכם ישירות, בלי שתעלה כלום.

Starter — סיכום Board Pack מ-Drive
Access the file "TechFlow Board Pack Q2 2026" from my Google Drive. Summarize: 1) Key financial highlights 2) Metrics below target 3) Top 3 risks mentioned. Format: 3 sections, bullet points, English.
Advanced — השוואה בין רבעונים מ-Drive
Compare the Q1 vs Q2 Board Packs from my Drive — what metrics are trending in the wrong direction? For each declining metric show: Metric | Q1 | Q2 | Change | Why it matters. Language: English, board-ready.
✓ רשימת בדיקה לאחר התרגיל
חיברתי את Google Drive ואישרתי הרשאות
Claude שלף את הקובץ בלי שהעליתי אותו ידנית
קיבלתי סיכום ב-3 חלקים (highlights / below target / risks)
הרצתי את ההשוואה בין Q1 ל-Q2
זיהיתי אילו מדדים במגמה שלילית
טיפ אבטחה: אחרי שסיימת, אפשר לבטל את ההרשאה ב-Settings → Connectors. אתה תמיד בשליטה על מה Claude יכול לראות.
