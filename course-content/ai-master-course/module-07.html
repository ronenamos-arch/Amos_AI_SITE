מה זה Connector?

במקום להעלות קבצים — Claude מתחבר ישירות

עד עכשיו, כדי ש-Claude ינתח דוח, היית מוריד אותו, מעלה ל-Claude, ומדביק. עם Connector (המבוסס על תקן ה-MCP של Anthropic) — Claude מתחבר ישירות ל-Google Drive, Notion, SharePoint או מערכות ה-ERP שלך, וקורא את הקבצים באופן מאובטח ואוטומטי.

📋
בלי Connector — Copy-Paste ידני
מוריד קובץ → מעלה ידנית → מדביק נתונים. בכל פעם מחדש. כמו להעתיק מסמך ביד עם סיכון גבוה לפערי גרסאות.
🔌
עם Connector — כבל ישיר ומאובטח
Claude מחובר ישירות למקור ושולף את הקובץ העדכני לבד. כמו לחבר כבל מהיר — המידע הפיננסי זורם בזמן אמת.

מתי להעלות קובץ ומתי לחבר מערכת

שני הנתיבים עובדים מצוין — אך חיבור Connector חוסך שעות עבודה יקרות כאשר הקבצים והנתונים מתעדכנים באופן שוטף.

קריטריון העלאה ידנית (Upload) חיבור ישיר (Connect)
עדכניות נתונים תמונת מצב רגעית בלבד (Snapshot) תמיד הגרסה העדכנית ביותר בזמן אמת
מאמץ תפעולי הורדה + העלאה ידנית בכל שיחה מחדש חיבור חד-פעמי — שליפה אוטומטית לפי דרישה
טיפול בריבוי קבצים נוח לקובץ בודד או ניתוח נקודתי מצוין לתיקיות שלמות, ארכיונים וחיפוש רוחבי
התאמה למחלקת כספים קובץ חד-פעמי, סודי או בדיקה רגעית תהליכים חוזרים (סגירת חודש, דוחות דירקטוריון)
פרטיות ואבטחת מידע

מה Claude רואה — ומה נשאר מוגן לחלוטין אצלך

👁️ מה Claude ניגש אליו
• רק הקבצים והתיקיות שאתה מבקש במפורש בשיחה
• רק לאחר אישור הרשאה (Authorization) מפורש שלך
• קריאה בזמן השיחה הפעילה בלבד — ללא שמירה בלתי מורשית
🔒 מה נשאר מוגן בארגון
• הסיסמאות ופרטי ההתחברות שלך — לעולם לא נחשפים
• שליטה מלאה בהרשאות (Read-Only) ואפשרות ניתוק מיידית
• כל יתר הקבצים והמידע שלא נתבקשו — אינם נסרקים ואינם נקראים
מדריך מעשי: חיבור Google Drive

4 שלבים פשוטים לחיבור המערכת

1
Settings → Connectors → Google Drive
פתח את הגדרות החשבון ב-Claude, גש ללשונית Connectors ובחר את Google Drive מרשימת החיבורים הזמינים.
claude.ai / settings / connectors Connectors Hub
מסך Connectors בהגדרות החשבון — בחירת מקור הנתונים לחיבור ישיר.
2
בדוק את ה-Tools של ה-Connector
לפני החיבור, סקור אילו פעולות (Tools) ה-Connector חושף — קריאה, חיפוש או יצירת מסמכים. כך תדע בדיוק מה Claude מורשה לבצע.
claude.ai / connectors / tools-scope Tools & Capabilities
סקירת הכלים והפעולות המוגדרים ב-Connector לפני מתן ההרשאה.
3
אשר הרשאות (Authorize)
התחבר לחשבון ה-Google שלך ואשר אילו Tools מותרים — קריאה בלבד (Read-only) או גם כתיבה. אתה שומר על שליטה מלאה בכל שלב.
claude.ai / connectors / permissions Security & Permissions
הגדרת רמת ההרשאות — קביעת מדיניות גישה מוגבלת ומאובטחת.
4
בקש קובץ לפי שם ישירות בשיחה
פשוט פנה ל-Claude בשפה טבעית: "Access the file TechFlow Board Pack from my Drive" — Claude ישלוף, יקרא וינתח את המידע ישירות ללא צורך בהעלאה ידנית.
ה-Insight החשוב ביותר למנהל הכספים

Connector הופך את Claude מ"כלי שמנתח רק מה שהדבקת לו" ל"עוזר פיננסי חכם שיודע איפה הקבצים שלך נמצאים". במקום לבזבז זמן בחיפוש, הורדה והעלאה של דוחות — פשוט מבקשים אותם בשמם והניתוח מתבצע מיד.

תרגיל 07 חיבור Google Drive וניתוח Board Pack מחובר ישירות

חבר את Google Drive לפי 4 השלבים שלמעד. ודא שיש ב-Drive קובץ בשם TechFlow Board Pack Q2 2026 (ניתן ליצור קובץ דמה או להשתמש בקובץ קיים). לאחר מכן הרץ את ה-Prompts — Claude ישלוף את המידע ויסכם אותו ישירות ללא העלאה ידנית.

Starter — סיכום Board Pack מתוך ה-Drive
Access the file "TechFlow Board Pack Q2 2026" from my Google Drive. Summarize: 1) Key financial highlights 2) Metrics below target 3) Top 3 risks mentioned. Format: 3 sections, bullet points, English.
Advanced — השוואת מגמות בין רבעונים מ-Drive
Compare the Q1 vs Q2 Board Packs from my Drive — what metrics are trending in the wrong direction? For each declining metric show: Metric | Q1 | Q2 | Change | Why it matters. Language: English, board-ready.
📋 רשימת בדיקה והערכה לאחר התרגיל
סמן כל שלב שהשלמת בהצלחה כדי לוודא שליטה מלאה בחיבור וניהול Connectors:
חיברתי את Google Drive (או סביבת בדיקה) ואישרתי הרשאות פעולה מאובטחות.
Claude שלף בהצלחה את קובץ ה-Board Pack מתוך ה-Drive ללא העלאה ידנית.
קיבלתי סיכום פיננסי ממוקד ב-3 חלקים (Key Highlights / Below Target / Top Risks).
הרצתי בהצלחה את שאילתת ההשוואה בין הרבעונים (Q1 מול Q2) בפורמט Board-Ready.
זיהיתי אילו מדדים במגמה שלילית והבנתי כיצד לבטל או להגביל הרשאות בהגדרות.
טיפ אבטחה וניהול גישה: לאחר סיום התרגיל, בדוק כיצד ניתן לנהל או לנתק את החיבור דרך Settings → Connectors. במחלקת כספים תמיד שומרים על שליטה מלאה ומדיניות Least Privilege.
