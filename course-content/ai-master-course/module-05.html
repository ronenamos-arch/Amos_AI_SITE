מה זה Skill?

כרטיס מתכון ש-Claude זוכר — כדי שלא תכתוב את אותו Prompt פעמיים

תאר לעצמך שבכל סוף חודש אתה מקליד מחדש את אותו ה-Prompt המורכב עבור Variance Commentary או דוח ניהולי. Skill הוא הדרך לקבע את הכללים וההוראות האלה פעם אחת — וכל פעם שתצטרך, פשוט להפעיל אותם בשם ה-Skill.

זה בדיוק כמו כרטיס מתכון של שף: הגדרת פעם אחת את המרכיבים, הכללים והפורמט המבוקש, ומאז כל מי שמפעיל את הכרטיס במחלקת הכספים מקבל בדיוק את אותה תוצאה תקנית ועקבית. ה-Skill הופך לזיכרון המוסדי של הצוות שלך.

האנטומיה של Skill

3 רכיבי היסוד של כל Skill פיננסי

כל Skill מקצועי מורכב משלושה חלקים ברורים שמבטיחים אפס סטיות בביצוע:

01 // NAME
Name — שם הכלי
שם קצר, חד ואינטואיטיבי שבו תפעיל את ה-Skill. לדוגמה: Variance Commentary או ERP-Cleaner.
02 // INSTRUCTIONS
Instructions — הוראות
בדיוק מה Claude צריך לעשות: מבנה חישובי, סגנון שפה, אורך מקסימלי, ומגבלות בקרת איכות חשבונאיות. הלב של ה-Skill.
03 // EXAMPLES
Examples — דוגמת זהב
דוגמת Input ו-Output אחת (Few-Shot). זהו המפתח שמבטיח ש-Claude יחקה את הפורמט הרצוי בדיוק של 100%.

Variance Commentary FP&A Core
מטרה: מקבל נתוני שונות מול תקציב ומחזיר Commentary ממוקד של 2 משפטים לכל שורה: ניתוח הסיבה + צעד אופרטיבי.
תזמון: בכל סגירת חודש/רבעון לקראת הכנת חבילת הדירקטוריון וההנהלה (Board Pack).

מטרה: בונה סקירה חודשית אחידה — Key Highlights, מדדי KPIs עם אינדיקטורים, ניתוח סיכונים ותחזית קדימה (Outlook).
תזמון: סקירה תקופתית להנהלה הראשית, באותו מבנה עקבי בכל חודש ללא תלות באנליסט המכין.

מטרה: מנקה ייצוא גולמי ממערכת ה-ERP — מתקנן שמות כרטיסים, מסיר כפילויות, ממיר פורמט תאריכים ומסמן חריגות.
תזמון: לפני כל תהליך אנליזה או בניית מודל, כשהנתונים נמשכים בפורמט גולמי ומבולגן.

תרגיל 05 בניית Skill של Variance Commentary ובדיקה על TechFlow

צור Skill ייעודי ל-Variance Commentary לפי המבנה שלמטה, ולאחר מכן בדוק אותו על נתוני Q2 2026 של TechFlow. שים לב כיצד הפלט מתקבל במבנה אחיד, ברור ו-Board-Ready לכל אחת מחמש שורות הדוח.

Starter — הגדרת ה-Skill המלאה
Skill Name: Variance Commentary Instructions: When given financial variance data, produce commentary in this format: [Line Item] [Actual] vs [Budget] ([variance %]): [1 sentence explanation] [1 sentence action/outlook]. Tone: CFO professional. Language: English. Max 2 sentences per line. Example input: "Revenue: $22.4M vs $23.0M budget (-2.6%)" Example output: "Revenue came in at $22.4M, -2.6% below budget, driven by Enterprise underperformance of -6.7%. Management is reviewing pipeline acceleration targeting $1.2M recovery in H2."
Advanced — הרצה על 5 שורות ה-P&L של TechFlow
Run Variance Commentary Skill on TechFlow Ltd Q2 2026 data: Revenue: $22.4M vs $23.0M (-2.6%) COGS: $8.2M vs $7.6M (+7.9%) Gross Profit: $14.2M vs $15.4M (-7.8%) OpEx: $10.3M vs $9.9M (+4.0%) EBITDA: $3.9M vs $5.5M (-29.1%)
📋 רשימת בדיקה והערכה לאחר התרגיל
סמן כל שלב שהשלמת בהצלחה כדי לוודא שליטה בהטמעת Skills ארגוניים:
הגדרתי בהצלחה Skill עם Name + Instructions + דוגמת זהב (Example).
הרצתי את ה-Skill על 5 שורות הדוח של TechFlow וקיבלתי פלט במבנה אחיד.
