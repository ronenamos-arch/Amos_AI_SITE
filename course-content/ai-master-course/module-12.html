הצלילה לעומק — 5 ה-Use Cases המשמעותיים ביותר

אלה חמשת השימושים המובילים שכל מנהל כספים, חשב ואנליסט FP&A צריכים לשלוט בהם. לחץ על כרטיס לצפייה ב-Prompt המלא ובהסבר המעשי:

#12 Variance Analysis — ניתוח שונות תקציב FP&A / Variance ⚡ חיסכון: 3.5 שעות בחודש

משווה Actual מול Budget לכל שורה ב-P&L, מחשב סטייה נומינלית ב-$ ובאחוזים, ומסמן אוטומטית חריגות מהותיות. מהווה את אבן היסוד של כל תהליך סגירת חודש ניהולי.

Prompt מוכן להרצה (Use Case #12) Language: English / Data: TechFlow
Perform a variance analysis for TechFlow Q2 2026: Revenue: Actual $22.4M vs Budget $23.0M COGS: Actual $8.2M vs Budget $7.6M Gross Profit: Actual $14.2M vs Budget $15.4M OpEx: Actual $10.3M vs Budget $9.9M EBITDA: Actual $3.9M vs Budget $5.5M For each line: calculate $ variance, % variance, and write 1-sentence management commentary. Format: Markdown table. Language: English.
#15 Management Commentary — דוח מילולי להנהלה Board / Commentary ⚡ חיסכון: 2 שעות לדוח

הופך טבלת סטיות מספרית יבשה לפסקאות הסבר ניהוליות חדות ומוכנות ל-Board Pack. ניסוח של משפט הסבר + משפט פעולה אופרטיבית בטון CFO מקצועי ומדויק.

Prompt מוכן להרצה (Use Case #15) Tone: CFO Executive
Given the following financial variances: - Enterprise Revenue: -6.7% vs Budget ($14.0M vs $15.0M) - Server & Hosting COGS: +12.5% vs Budget ($4.5M vs $4.0M) - R&D OpEx: +8.3% vs Budget ($5.2M vs $4.8M) Generate executive CFO commentary for our Board of Directors pack. Requirements: Exactly 2 sentences per bullet: (1) root cause analysis, (2) corrective action & H2 outlook. Professional, crisp financial tone.
#45 Trial Balance Cleanup — טיוב מאזן בוחן Data Ops / Accounting ⚡ חיסכון: 5 שעות לפני סגירה

מנקה ומסדר מאזן בוחן גולמי שנמשך מה-ERP: מתקנן שמות כרטיסים, מסיר שורות ביתרות אפס, מאתר כפילויות וממיין לפי היררכיית החשבונות החשבונאית.

Prompt מוכן להרצה (Use Case #45) Format: Clean Normalized Table
Review the raw Trial Balance below. Perform the following normalization tasks: 1. Standardize account descriptions (Proper Case, eliminate trailing numbers/symbols). 2. Remove all zero-balance accounts where both Debit and Credit are 0. 3. Check mathematical balance (Total Debit must equal Total Credit). Flag any difference. 4. Categorize each account into: Current Assets, Non-Current Assets, Current Liabilities, Long-term Liabilities, Equity, Revenue, COGS, OpEx. Format output as a markdown table with audit summary.
#77 GL & Subledger Reconciliation — התאמת ספר ראשי Audit / Close ⚡ חיסכון: 4 שעות בחודש

משווה יתרות בספר הראשי (GL) מול תתי-ספרים או מקורות חיצוניים (בנקים, ספקים, שכר), מאתר פערי התאמה ומסווג כל פער (תזמון, טעות סכום או תנועה חסרה).

Prompt מוכן להרצה (Use Case #77) Accounting Workpaper
Perform a General Ledger to Subledger reconciliation: GL Ending Balance: $4,850,200 Subledger (AP Aging) Balance: $4,630,000 Net Variance: $220,200 Given the unposted journal entries and timing records, build a formal Reconciling Items Schedule: - Classify each reconciling item (Timing difference, Currency FX, Missing invoice, Misposting). - State clearly whether an adjusting journal entry (AJE) is required. - Provide final Adjusted GL Balance matching the Subledger.
#79 FX Impact Analysis — ניתוח השפעת הפרשי שער Treasury / Multi-Currency ⚡ חיסכון: 3 שעות ברבעון

מפריד בצורה מתמטית נקייה בין השפעת שינויי שער חליפין (FX Effect) לבין שינוי אורגני בנפח ובפעילות. קריטי לחברות גלובליות הפועלות בריבוי מטבעות (USD, EUR, ILS).

Prompt מוכן להרצה (Use Case #79) Constant Currency Modeling
Perform an FX Bridge Analysis for TechFlow European Revenue (EUR): Q1 Actual: EUR 5,000,000 at EUR/USD 1.08 = $5,400,000 Q2 Actual: EUR 5,400,000 at EUR/USD 1.04 = $5,616,000 Calculate: 1. Organic Volume/Price growth in EUR and constant-currency USD. 2. FX Headwind / Tailwind impact in USD. 3. Create a waterfall summary from Q1 Reported Revenue to Q2 Reported Revenue. 4. Provide a 2-sentence executive explanation for the investor update.

4 שלבים מ-Use Case בספרייה לפלט פיננסי מושלם

הספרייה היא בסיס עוצמתי להאצה. השיטה המוכחת לעבודה יעילה מורכבת מארבעה שלבים:

1
Scan — איתור
סרוק את 22 הקטגוריות או השתמש בחיפוש ב-102-Prompt.html כדי למצוא את ה-Use Case המדויק.
2
Adapt — התאמה
החלף את מספרי ונתוני הדוגמה בנתוני האמת של החברה שלך — שמות חשבונות, תקופה וסכומי הדוח.
3
Run — הרצה
הזן ל-Claude. בדוק שהפלט עומד בדרישות המבנה, בדיוק החשבונאי ובקהל היעד שביקשת.
4
Iterate — שיוף
המשך את השיחה: "הוסף עמודת שינוי %", "קצר לפסקה אחת להנהלה", או "הפוך לטבלת Artifacts".
טיפ זהב למנהלי כספים וחשבים

Format: Markdown table. Language: English.
Advanced — שרשור תהליך עבודה משולב (#12 + #15 + #77) Multi-Stage Finance Workflow
בצע תהליך עבודה משולב בשלושה שלבים על נתוני TechFlow Q2 2026: שלב 1 (Use Case #12) — Variance: חשב סטיות $ ו-% לכל שורה ב-P&L וסמן חריגים מעל $200K או 5%. שלב 2 (Use Case #15) — Commentary: כתוב Management Commentary של משפט אחד לכל שורה חריגה, טון CFO, אנגלית. שלב 3 (Use Case #77) — GL Recon: עבור שורת COGS, בנה רשימת reconciling items היפותטית שתסביר את הסטייה של +$600K, מסווגת לפי סוג (תזמון / סכום / חסר). פורמט: 3 חלקים נפרדים עם כותרות. שמור על אותו הקשר חברה לאורך כל השלבים.
