מסגרת הפרומפט H·T·M·L

בריף בן ארבע אותיות שהופך הנחיה של CFO לדשבורד מוכן להנהלה, להורדה מיידית

טכניקת פרומפטינג

כל הזמנה טובה מתחילה מבריף מדויק. לפני שפונים ל-Claude, בונים את הבקשה לפי מסגרת H·T·M·L — ארבעה ממדים שנותנים ל-Claude את כל מה שהוא צריך כדי להפיק ארטיפקט של ממש, לא רק פסקת ניתוח.

קובץ HTML להפצה (Hostable)
מבקשים מ-Claude להפיק קובץ HTML יחיד, עצמאי לחלוטין — כל הסקריפטים, העיצוב והגרפים משולבים בפנים או נטענים מ-CDN. כל חבר הנהלה פותח אותו בדפדפן בלי התחברות, בלי אפליקציה ובלי פנייה ל-IT. שולחים כקובץ מצורף במייל, מארחים ב-Netlify, או מטמיעים ב-Notion.
"Output a single fully self-contained HTML file. No external dependencies. Must render offline and be shareable as an attachment."
H
קהל היעד ומקרה השימוש (Target)
מגדירים מי ישתמש בדשבורד ואיזו החלטה הוא צריך לתמוך בה. CFO שבודק ביצועים צריך פריסה שונה מאנליסט שחוקר וריאנסים — וחבילת דירקטוריון שונה מכלי תפעולי פנימי. אומרים ל-Claude מי המשתמש, מה ההקשר ואיזו שאלה הדשבורד אמור לענות עליה.
"Audience: CFO and board members. Use case: monthly performance review — they need to see at a glance whether we are on track vs. budget and where to probe. No interactivity needed; clarity and narrative hierarchy above all."
T
מדגם מהנתונים שלי (My data)
מעלים פלח קטן ומייצג מהנתונים האמיתיים — כמה שורות והעמודות המרכזיות — במקום את כל קובץ העבודה. Claude משתמש במבנה ובמספרים כדי לחווט את הדשבורד נכון, בלי לדרוש את מלוא הדאטהסט מראש.
"I'm attaching 3 months of data as a sample. Use this structure and these columns to build the dashboard — I will provide the full dataset once the layout is confirmed."
M
פריסה ומראה (Layout & Look)
קובעים כיוון עיצובי. משלבים עם סקיל Theme Factory לתוצאה מקצועית, או מתארים אסתטיקה משלכם — "כהה וניהולי", "נקי ומינימלי", "ירוק יער עם נגיעת זהב".
"Dark executive style. Sidebar navigation. White metric cards. Serif typography for headline numbers."
L
דוגמה מלאה — בריף H·T·M·L שלם

"Build an FP&A dashboard for a SaaS company. Hostable HTML file — single self-contained output, no external dependencies, must render offline. Target audience: CFO and board — monthly performance review, needs at-a-glance budget vs. actuals with clear narrative hierarchy, no interactivity required. My data attached as a 3-month sample — use this structure to wire the dashboard; I will provide the full dataset once the layout is approved. Layout: dark executive theme, sidebar navigation, large metric cards, subtle grid lines on all charts."

שואבים השראה עיצובית מ-Dribbble

מוצאים עיצוב שאתם מעריכים ומבקשים מ-Claude לשחזר את האסתטיקה עבור הנתונים שלכם

מחקר עיצובי

Dribbble (dribbble.com) הוא המאגר המוביל של אומנות ממשק — כולל אוסף רחב של דשבורדים פיננסיים ברמה גבוהה. במקום לתאר במילים מה רוצים, מוצאים רפרנס ויזואלי ונותנים ל-Claude להנדס בהיפוך את האסתטיקה עבורכם.

איך לחפש ב-Dribbble

מונחים שמעלים עבודות איכותיות: "finance dashboard dark", "SaaS metrics executive", "CFO report design", "FP&A UI minimal", "KPI dashboard luxury".

finance dashboard darkSaaS metrics UIKPI executive

מה לספק ל-Claude

מעלים צילום מסך, או מדביקים ישירות את קישור ה-Dribbble. מנחים את Claude: "Match this layout and palette — adapt it to display our FP&A metrics with the same visual weight."

screenshot uploadURL reference

מה לחלץ מרפרנס

שמים לב לסידור הכרטיסים, ההיררכיה הטיפוגרפית, בחירת הגרפים, טמפרטורת הצבע, ואיך הקומפוזיציה מכוונת תשומת לב למספר הראשי בעמוד.

מתארים במה אתם מעריכים

לא מדביקים רק תמונה — מנסחים העדפה. "אני מעריך את הסיידבר הכהה, המספר הראשי הגדול, וקווי הרשת המאופקים בגרף."

בריף מבוסס־רפרנס

"Attached is a Dribbble reference I find most distinguished — dark background, ivory cards, fine-weight typography, generous white space. Recreate this aesthetic precisely, but replace the content with our FP&A metrics: Revenue, EBITDA Margin, Headcount, and Free Cash Flow."

05

מזמינים דשבורד חי מבוסס AI

דשבורדים שחושבים — הטמעת האינטליגנציה של Claude ישירות בארטיפקט

מתקדם

מעבר לדוח סטטי, Claude יכול לבנות ארטיפקטים מבוססי-AI — דשבורדים שמתקשרים חזרה ל-API של Claude, ומאפשרים לכל צופה לשאול שאלות על הנתונים בשפה חופשית ולקבל ניתוח מיידי ומנומק. בשילוב עם חיבורי נתונים חיים, זה מפיק כלי דיווח ברמה של ממש.

מחברים מקור נתונים — מפעילים Google Sheets, Excel Online או Salesforce בהגדרות המחברים של Claude. מספרים חיים זורמים לארטיפקט אוטומטית בכל צפייה.
i
מטמיעים שורת שאילתות AI — מנחים את Claude להוסיף שדה טקסט שקורא ל-API של Anthropic עם ההקשר הפיננשי שלכם כפרומפט מערכת, כך שבעלי עניין יכולים להקליד "למה ה-EBITDA התכווץ ברבעון השלישי?" ישירות בתוך הדשבורד.
ii
מאוטמים פרשנות וריאנס — כפתור "צור פרשנות" אחד מפעיל את Claude לספר את השינויים בתקופה ולהעלות חריגות, ומתעדכן עם כל מחזור נתונים.
iii
מוסיפים בקרות תרחיש — סליידרים אינטראקטיביים לצמיחת כוח אדם, שיפור מרווח גולמי, או צמצום נטישה, מופעלים על ידי מנוע החישוב של Claude למידול "מה אם" מיידי.
iv
בריף לדשבורד מבוסס-AI

"Build an FP&A dashboard artifact containing: (1) live KPI cards, (2) a trend chart via Chart.js, (3) a scenario model with adjustable sliders, and (4) a natural-language query input — using the Anthropic API to answer questions with the dashboard data held as context in the system prompt."

06

מורידים ומפיצים את קובץ ה-HTML

שלושה ערוצים שדרכם הדשבורד שלכם מגיע לקהל היעד בלי חיכוך

הפצה

היתרון הייחודי של ארטיפקט HTML עצמאי הוא שהוא לא דורש שום תשתית להפצה. קובץ יחיד — בדרך כלל מתחת למגה-בייט — נפתח בכל דפדפן ובכל מכשיר, בלי התחברות, בלי אפליקציה ובלי פנייה ל-IT.

כארטיפקט של Claude

מורידים ישירות מלוח הארטיפקטים של Claude. כל הגרפים, הפונטים והעיצוב משולבים בפנים. מפיצים כדואר אלקטרוני כקובץ מצורף — בלי הכנה נוספת.

כעמוד מתארח

שמים את הקובץ ב-Netlify Drop, GitHub Pages, או כל אחסון סטטי אחר. כתובת URL להפצה נוצרת תוך רגעים — מתאים לחבילות דירקטוריון, עדכוני משקיעים ודוחות חודשיים.

בתוך מצגת

מטמיעים את ה-HTML ב-Notion, Confluence או SharePoint. או פותחים בכרטיסייה בדפדפן במהלך ישיבת דירקטוריון — הגרפים והסליידרים האינטראקטיביים נטענים במלוא הנאמנות להצגה חיה.

מוודאים שהקובץ באמת ניתן להפצה

"Ensure the final HTML file is entirely self-contained. All Chart.js scripts, fonts, and CSS must be inlined or loaded from a CDN. The artifact must open and render with complete fidelity in the absence of an internet connection."

07

משכללים דרך שיחה, לא דרך מפרט

מתייחסים ל-Claude כשותף עיצוב — נותנים הערות כמו לאנליסט בכיר

גישת עבודה

ההתאמה המשמעותית ביותר לאנשי כספים חדשים ל-Claude Artifacts: לוותר על הדחף לכתוב בריף מושלם. החוזק האמיתי של Claude הוא איטרציה — כל הנחיה היא עדכון חי לארטיפקט. מתייחסים אליו כמו לאנליסט מוכשר שלא מתעייף, לא שוכח, ומשתפר עם כל חילופי דברים.

פותחים רחב, סוגרים מדויק — מקימים דשבורד עובד בתוך שניים-שלושה חילופי דברים לפני שמשכללים. פרופורציה, היררכיה ובחירת גרפים קודם; טיפוגרפיה וצבע אחרונים.
i
מתייחסים למה שרואים — "גרף העמודות של ההכנסות בפינה השמאלית העליונה — הפכו אותו לגרף מפל שמראה וריאנס רבעוני." Claude שומר מודעות מלאה למצב הנוכחי של הארטיפקט.
ii
